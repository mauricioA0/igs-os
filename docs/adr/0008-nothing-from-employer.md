# ADR 0008 — Nothing from the author's employer

Status: Accepted · 2026-10-22

## Context
IGS OS is a public portfolio project built for a job application. The author's current employer's code, infrastructure and credentials are under NDA.

## Decision
IGS OS uses no code, services, data, cloud projects or API keys from the current employer. It runs on the author's personal GCP project and personal API keys. Experience gained at work may inform design, but every line is written fresh, and all demo data is fictional.

## Consequences
- The repo can be public without legal or compliance risk.
- Nothing can be copied over, even when a similar component exists elsewhere.
